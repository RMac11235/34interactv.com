VaultDrill

실제로 테스트를 마친 백업.

월 $5.99부터. 7일 무료 체험, 카드 등록 불필요.

VaultDrill은 Windows PC를 USB 드라이브, 폴더, NAS, 또는 이미 가지고 있는 클라우드 스토리지 계정에 백업합니다. 백업은 PC를 떠나기 전에 PC에서 암호화됩니다. 설정한 일정(기본값은 매주)에 따라 VaultDrill이 파일 중 무작위 표본을 임시 폴더에 복원하고, 하나하나 확인한 뒤 삭제하고, 백업이 여전히 복원되는지 알기 쉬운 말로 알려 줍니다.

Windows PC를 백업하고 있고 그 백업이 여전히 복원되는지 알고 싶다면, VaultDrill이 바로 그 일을 위해 만들어졌습니다. 백업은 귀하가 소유한 저장소에 하며, 저희는 데이터를 절대 보관하지 않습니다. 예약된 Restore Drill이 파일 표본을 테스트해 백업이 여전히 복원되는지 알려 줍니다. 모든 요금제와 체험판에 포함된 휴대폰 앱은 페어링된 각 PC를 초록, 주황, 빨강으로 표시합니다.

주요 기능

  1. 내가 소유한 저장소에 백업. 외장 드라이브, 다른 PC의 폴더, NAS 공유 폴더, 또는 본인의 Backblaze B2, Amazon S3, SFTP 계정. 스토리지 비용은 제공업체에 직접 지불하며, 저희는 데이터를 절대 보관하지 않습니다.
  2. Restore Drill. 파일 표본을 예약된 일정에 따라 시험 복원하고, 날짜가 기록된 결과를 제공합니다.
  3. 탐색 및 복원. 저장된 어느 시점이든 열어 원하는 위치로 파일을 되돌리세요.
  4. 원격 측정 없음. 계정도 분석 도구도 없습니다. 진단 데이터는 귀하가 직접 지원팀에 보내기로 선택한 경우에만 공유됩니다.

휴대폰용 VaultDrill

휴대폰 앱은 페어링된 각 PC를 초록, 주황, 빨강으로 이유와 함께 표시하고, 마지막 백업과 Restore Drill 기록을 보여 주며, 지문이나 휴대폰 PIN 확인 후 Restore Drill 실행, 일정 일시 중지 또는 재개, 최근 로그 읽기를 할 수 있게 해 줍니다. 앱의 어떤 작업도 파일을 삭제하거나 덮어쓰거나 변경할 수 없습니다. 모든 요금제와 체험판에 포함되어 있습니다.

테스트 환경에서 찍은 휴대폰 앱 스크린샷입니다.
